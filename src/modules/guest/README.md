# Local guest workspace (Local Profile)

**Continue as Guest** on the sign-in screen opens it. On first use it asks for a display name, with an optional picture and an optional PIN (4–8 digits, kept only as a salted scrypt hash, as the app lock's PIN). No email, verification, server registration, required picture or AI model setup is involved: the window returns before the account's picture gate and setup wizard. The header shows "<name> · Local Profile · Saved on This Device" and, separately, an online/offline indicator. Apps that need an account (Chat, Mail, Drive & Files, company records, shared workspaces, HR, CRM, the AI assistant) are listed as locked with "Needs a WorkSuite account"; the window's IPC allowlist cannot reach them.

With a PIN, each Local Profile window asks for it before any local data is read, and so does an account's import review. Five wrong PINs wait a minute. A forgotten PIN cannot be recovered; Delete All starts again.

The guest workspace runs in a separate window and never initializes account state. Its main-process IPC handlers accept only registered local workspace windows. Guest meeting and local windows are excluded from account broadcasts, workspace IPC, the private API proxy and the private local-cache protocol.

Data lives in `profiles/default/guest-workspace.sqlite`, separate from account caches. Its schema is versioned with `PRAGMA user_version` and migrated in place on update (version 2 adds the `profile` table); a file from a newer WorkSuite is refused rather than changed. SQLite uses synchronous FULL writes; the database file has device-user-only permissions. Guest data is not encrypted or uploaded automatically. The UI explains that it belongs to the device profile and that exported JSON backups must be kept private.

Notes are plain text. Each list has a search (every word, case- and accent-insensitive, title and text). Tasks have completion, due dates and reminders. Events have absolute start/end instants and reminders; the monthly view displays device-local dates. Reminders are checked every 15 seconds while WorkSuite runs, including in the background. Missed reminders can appear on reopening; operating-system notification settings may suppress them. Delivery acknowledgments survive restarts and backup restore.

Export/restore use a versioned JSON backup up to 20 MB (`format: "worksuite-local"`, version 2 adds the profile's name and picture, never the PIN; version 1 files still restore); writes are capacity-limited so every dataset remains restorable. Restore first validates the whole file and previews how many notes, tasks and events it adds and how many identical items it skips, writing nothing; only confirming that preview writes. It merges records without overwriting, and names the profile only on a device that has none. Delete All requires a typed confirmation and removes the profile, its PIN, local records, meeting destinations and import history. User-exported backup files remain under the user's control.

**Sign In / Create Account** opens the main window's sign-in; the Local Profile is not changed by signing in. An authenticated account receives only an import offer count (and the profile's name). Review is explicit and reads account titles to identify potential duplicates. The preview names the account and organization, lets the user select items, and defaults to skipping potential duplicates. Confirmed import uses frozen account credentials and origin, checks the account and each local revision, supplies stable Idempotency-Key headers, and records completed fingerprints per account. Local originals remain; retries skip completed content. Notes/events belong to the selected user; tasks use the selected organization. Existing account permissions still apply.

Join Meeting by link or code opens the guest meeting window with the profile's display name suggested (still editable). Meeting joining depends on desktop #85 and server Communication 1.3.0. A device can use its local tools without any server or account; live meetings need internet and a guest-enabled meeting server.
